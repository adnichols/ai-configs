# Supervise an active task

Identify the user's named worker task and desired outcome before observing it. Use native task coordination tools for another user-owned Codex task, or native collaboration messaging for an existing subagent. Do not create a replacement implementation agent or assume an OMP hub or Pi session.

Read compact progress snapshots and compare activity with scope, constraints, and completion evidence. Send bounded corrective guidance only within the requested supervision relationship. Avoid interrupting useful work merely to request status. Escalate real scope or authority issues, and distinguish stalled activity from an external wait.

Return deviations, guidance delivered, remaining concerns, and observed completion evidence. Supervision does not authorize changing the worker's repository, posting messages to people, or claiming its unverified outcome complete.
