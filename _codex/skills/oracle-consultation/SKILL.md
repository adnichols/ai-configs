# Consult on one unresolved decision

Use for a consequential technical choice that remains unresolved after targeted evidence, drift from locked constraints, or bounded review non-convergence. Do not use for routine discovery, mechanical edits, tests, or a decision already settled by an authoritative source.

Request a bounded read-only native oracle under the runtime contract. Preserve relevant inherited context; if the tool cannot combine an inherited fork with a selected model, inherit the parent rather than dropping needed context. Otherwise use the configured oracle default with a complete context packet.

The packet names one decision, constraints, evidence, credible options, the driver's current recommendation and uncertainty, advisory authority, and stopping condition. End with one narrow question. For review non-convergence include the immutable candidate, attempts, disagreement, and allowed escape dispositions.

Verify the response against evidence. Record accepted, partially-accepted, rejected, or escalated with reasons before acting. The oracle cannot authorize a scope expansion, external action, or override of user intent. Consult once per distinct unresolved decision; do not retry until advice agrees with the driver.
