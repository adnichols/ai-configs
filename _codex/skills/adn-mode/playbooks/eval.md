# Eval

Read the parent skill and [Codex runtime contract](../references/codex-runtime.md).

State the behavioral claim, fixed task corpus, allowed actions, scoring criteria, model configuration, and budget. Compare baseline and candidate under the same conditions in isolated temporary workspaces. Label outputs without exposing the candidate identity to the judge when feasible. The driver owns executable experiments. Collect completion, correctness, authorization, tool failures, latency, and token evidence. Report inconclusive results honestly. Do not adopt a new upstream pin or deploy a candidate merely because a small eval passes.
