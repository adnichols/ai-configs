# Trace forensics

Read the parent skill and [Codex runtime contract](../references/codex-runtime.md).

Inspect the supplied profiling artifact with its native analysis tools. Record capture context, missing context, units, sampling limits, and the relevant hot paths or retention chain. Separate an observed cost from a causal explanation. Correlate with source when available. Return a supported diagnosis and a bounded follow-up experiment. Do not treat an old capture as proof of current runtime state.
