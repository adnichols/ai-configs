# Runtime forensics

Read the parent skill and [Codex runtime contract](../references/codex-runtime.md).

Treat diagnosis as the deliverable. Establish the live symptom and collect the cheapest useful traces, logs, or runtime instrumentation from the authorized target. Follow the actual platform's control skill. Test competing explanations and tie the surviving mechanism to observations. Remove task-owned temporary instrumentation when appropriate and preserve evidence. Return diagnosis, supporting observations, confidence, and the next discriminating test. Do not claim a production fix or edit the product unless requested.
