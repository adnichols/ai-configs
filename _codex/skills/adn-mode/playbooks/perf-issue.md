# Perf issue

Read the parent skill and [Codex runtime contract](../references/codex-runtime.md).

Establish a reproducible workload, environment, and baseline. Profile the relevant path and identify the measured bottleneck before optimizing. The driver changes one justified cause at a time and compares the same workload before and after. Check correctness and avoid optimizing a proxy unrelated to the user's symptom. Report measurements, measurement variance, tradeoffs, and unresolved bottlenecks. Do not broaden a one-off fix into an indefinite optimization program.
