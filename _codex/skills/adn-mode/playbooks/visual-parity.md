# Visual parity

Read the parent skill and [Codex runtime contract](../references/codex-runtime.md).

Identify the reference image or implementation, viewport, state, fonts, and interaction being matched. Inspect the visual input directly; use a vision-capable agent only if the driver cannot inspect it. Capture the actual implementation under comparable conditions. The driver makes scoped changes and compares fresh output, including interaction states that affect layout. Report remaining visible differences and the evidence. Do not call an inaccessible or unrendered screen verified.
