# Autopilot full

Read the parent skill and [Codex runtime contract](../references/codex-runtime.md).

Resolve the independent queue and the exact authority granted for implementation, PR publication, and merges. Process each item as a complete verified slice in the driving session, using bounded independent review where required. Keep evidence tied to the current candidate head. Merge only items for which the user has granted that authority and checks permit it. One item's blocker need not prevent work on another independent item. Do not create implementation-owner agents or cloud workers. Report each item's actual state and evidence.
