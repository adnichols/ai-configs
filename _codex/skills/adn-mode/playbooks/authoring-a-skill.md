# Authoring a skill

Read the parent skill and [Codex runtime contract](../references/codex-runtime.md).

Read the active Codex `skill-creator` instructions. Establish the intended trigger, non-trigger, inputs, output, and runtime dependencies. Preserve repository ownership and the existing invocation policy. Write the entrypoint and only necessary supporting resources. Validate frontmatter, relative references, tool availability, and realistic requests. Use a bounded independent read-only forward test for a complex change when available. Installation or publication follows the user's request, not a mandatory PR step.
