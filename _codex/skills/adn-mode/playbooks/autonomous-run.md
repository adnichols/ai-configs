# Autonomous run

Read the parent skill and [Codex runtime contract](../references/codex-runtime.md).

Define the requested outcome and completion evidence. Keep a task list and a decision trail for substantial unattended work. Implement and verify in bounded units in the driver. Delegate independent read-only work only when it advances the run. Resolve observable questions with evidence and continue authorized reversible work. Stop only at completion, cancellation, a genuine product decision, or an external blocker. Do not infer permission for messaging, merging, deployment, goals, or recurring automations from a request for persistence.
