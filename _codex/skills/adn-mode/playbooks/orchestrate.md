# Orchestrate

Read the parent skill and [Codex runtime contract](../references/codex-runtime.md).

Map the standing program into complete verifiable units, dependencies, and authorized publication boundaries. Keep one current program artifact with actual status and evidence links. The driver owns implementation and Git; bounded read-only scouts or reviewers may cover independent questions. Schedule work within available capacity instead of assuming cloud fleets. Reconcile requirements and shared state before starting each unit. Report completed outcomes and blocked dependencies without inventing progress from agent activity.
